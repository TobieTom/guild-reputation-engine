## Forum Proposal Template

### Title: [Proposal] Implement Reputation-Based Contribution Tracking

```
# Summary
Deploy reputation system to track member contributions across gaming, governance, and community.

# Problem
- No objective way to compare different contribution types
- Inactive governance delegates hold voting power
- Manual scholar tracking doesn't scale
- Community helpers go unrewarded

# Solution
Guild Reputation Engine - 6-category scoring:
- Gaming (30%): matches, wins, earnings
- Governance (25%): voting, proposals
- Community (25%): Discord, events
- Scholarship (20%): scholar management

# Budget
Implementation: $5,000-15,000
Monthly: $1,000-3,000

# Vote
For: Implement reputation system
Against: Do not implement
```
